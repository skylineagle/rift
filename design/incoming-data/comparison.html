Recommended behavior

  • One receipt raises the ring immediately. Hold for 180 ms, then fade for 200 ms using the existing ease-out token.
  • Further receipts extend the hold. Sustained traffic becomes a steady ring, with no packet-by-packet strobe.
  • Keep Edited as the persistent inner border and text. Receipt uses a separate outer layer. Pausing clears transient receipt.
  • Reduced motion keeps a steady recent-receipt ring and textual forwarding feedback. No traveling dots or repeated pulses.

Event contract for implementation

  • type=data, origin=received lights the source card, scoped to its profile. Receipt does not imply delivery.
  • Only origin=forwarded, delivered=true creates traveling seam dots.
  • Injection, failed delivery, status updates, and receipt alone create no forwarding dots.
  • Current particle code also represents injections and drops. This proposal intentionally narrows dot semantics; behavior changes belong to the implementation worker.
  • No production components, event handling, logger behavior, or logo assets changed.

Review sequence: Burst at A, Burst at B, sustained at Both, forwarding, Paused / edited, then reduced motion. Burst animation is an illustrative three-receipt sequence; production should retarget one opacity transition and extend its hold.
