# Rift logo approval drafts

A: Split R, recommended. B: Linked terminals. C: Duplex.

Each folder contains mark.svg, icon.svg, mono.svg, 512px transparent mark and mono PNGs, and icon PNGs at 16, 24, 32, 64, 128, 256, 512, and 1024px. PNGs were rendered directly from their SVG sources with rsvg-convert. Symbols have no font dependency. Wordmarks in comparison.html use system sans like the application.

Dark palette: amber #f59e0b, blue #38bdf8, tile #111113, border #2b2b30. These are approval drafts only. No installed icon or component has been changed.
