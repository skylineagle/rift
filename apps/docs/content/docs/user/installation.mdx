---
title: Installation
description: Install the Rift desktop app or CLI on Linux, macOS and Windows, from source, or as a container, and keep it up to date.
---

Get releases from the [latest release page](https://github.com/skylineagle/rift/releases/latest).

| Platform | Desktop app (includes the CLI) | CLI only |
| --- | --- | --- |
| Linux | `.deb`, `.rpm`, `.AppImage` | `rift-<version>-<arch>-unknown-linux-gnu.tar.gz` |
| macOS | `.dmg` (Apple Silicon or Intel) | `rift-<version>-<arch>-apple-darwin.tar.gz` |
| Windows | `.exe` installer | `rift-<version>-x86_64-pc-windows-msvc.zip` |

## Desktop app

Download the installer for your OS and run it. On macOS, open the `.dmg` and drag Rift to Applications.

The desktop app ships the `rift` CLI and puts it on your PATH:

| Installer | What happens |
| --- | --- |
| Windows `.exe` | Adds its folder to the user PATH. |
| Linux `.deb` / `.rpm` | Installs `rift` to `/usr/bin`. |
| macOS `.dmg` | On first launch the app links `rift` into `/usr/local/bin`, or `~/.local/bin` if that is not writable. An existing `rift` there is left alone. |
| Linux `.AppImage` | Does not install the CLI. |

On macOS, make sure `~/.local/bin` is on your PATH if the link ended up there. Open a new terminal and run `rift --version` to check.

## CLI archive

On Linux the archive needs no Rust toolchain. It runs on glibc 2.17 and later (for example Ubuntu 14.04 and newer) and needs `libudev1`.

```sh
curl -fsSL https://github.com/skylineagle/rift/releases/latest/download/rift-<version>-x86_64-unknown-linux-gnu.tar.gz | tar xz
sudo mv rift /usr/local/bin/
rift --version
```

Replace `<version>` with the release tag as it appears in the file name on the release page. Use `aarch64` instead of `x86_64` on ARM.

On macOS and Windows, download the matching archive, extract `rift` (`rift.exe` on Windows) and put it in a folder on your PATH.

## From source

You need [Rust](https://rustup.rs). On Linux you also need `libudev-dev`.

```sh
cargo install --git https://github.com/skylineagle/rift rift-cli
```

From a checkout:

```sh
cargo install --path crates/rift-cli
```

## Container

```sh
docker pull ghcr.io/skylineagle/rift
```

Images are published for `linux/amd64` and `linux/arm64`, tagged `:<version>` and `:latest`. See [Container](/docs/user/container).

## Updating

### CLI

```sh
rift update --check   # report whether a newer release exists
rift update           # download and replace the running binary
```

`rift update` only replaces the binary when it was installed from a release archive. For other install locations it prints what to do instead:

| Install location | Hint printed |
| --- | --- |
| Release archive (for example `/usr/local/bin/rift`) | `run rift update` |
| `~/.cargo/bin` | `run cargo install rift-cli --force` |
| Inside the desktop app (`.app/Contents/` on macOS, or next to the Windows uninstaller) | update the desktop app, it ships this CLI |
| `/usr/bin` (`.deb`, `.rpm`) | install the new package from the release page |

The download is checked against the release's `.sha256` file before it replaces the binary. Restart any running `rift` processes to use the new version. If the binary's folder is not writable, `rift update` tells you to retry with `sudo`.

`rift run` and `rift pipe` also print a one-line notice on stderr when a newer release exists. The check runs at most once every 24 hours and only when stderr is a terminal. Set `RIFT_NO_UPDATE_CHECK=1` to turn it off.

### Desktop app

The desktop app checks for updates when it starts and every 6 hours, and downloads them in the background. See [Updates](/docs/user/desktop/updates).
