---
title: Rift
description: Bridge TCP, UDP and serial (UART) endpoints. Pipe bytes between any two sides, inspect traffic, inject data live.
---

Rift joins two endpoints, side **A** and side **B**, and moves bytes between them in both directions.
Each side can be a TCP client, TCP server, UDP client, UDP server or a serial port.
It ships as a CLI (`rift`), a desktop app and a container image, all built on the same engine.
